# Railway Bot Builder

Telegram арқылы бірнеше Telegram bot жобасын басқаруға арналған Bot Builder.

## Мүмкіндіктер

- Жаңа child bot қосу
- Telegram token сақтау
- Python code versioning
- Syntax check
- Deploy
- Run
- Stop
- Restart
- Auto Restart
- Rollback
- Environment Variables
- Logs
- CPU/RAM Metrics
- SQLite database
- Railway deployment
