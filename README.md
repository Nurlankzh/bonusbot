# Бот Конструкторы (Telegram)

Бұл жүйе Telegram арқылы жаңа боттарды қосуға, олардың кодын тікелей чатта жазып, іске қосуға және қателерін/логтарын оқуға арналған.

## Railway.com-да Іске Қосу (Deployment)

1. **Жобаны Жүктеу:** GitHub-қа осы папкадағы файлдарды жүктеңіз немесе Railway арқылы тікелей қосыңыз.
2. **Environment Variables (Қоршаған Орта Айнымалылары):**
   Railway-де жобаның `Variables` бөлімінде мыналарды қосыңыз:
   - `BOT_TOKEN` = Сіздің негізгі басқарушы ботыңыздың токені (мысалы: 87291170... )
   - `ADMIN_ID` = Сіздің Telegram ID-іңіз (мысалы: 6303091468)
   - `DB_PATH` = `/app/data/bot_builder.db` (Бұл деректердің өшіп қалмауы үшін керек)
3. **Volume Қосу (Міндетті):**
   Деректер базасы (боттар, тарих, кодтар) әр рестарт сайын өшіп қалмауы үшін, Railway-де жобаңызға `Volume` қосыңыз және оны `/app/data` жолына (Mount Path) тіркеңіз.
4. **Deploy:** `Procfile` және `railway.json` баптаулары бәрін өздері автоматты түрде қосады.

## Қалай Жұмыс Істейді?
- Басқарушы ботқа `/start` деп жазыңыз.
- "Жаңа Бот Қосу" батырмасын басып, ботқа атау мен Токен беріңіз.
- "Жаңа Код Жазу" арқылы Python кодын жіберіңіз (Бот `BOT_TOKEN` айнымалысын автоматты түрде өзі қосады, сондықтан кодта тек `bot = Bot(token=BOT_TOKEN)` деп қолдана беріңіз).
- "Қосу" батырмасын бассаңыз, бот жеке процесте іске қосылады. Егер кодта қате кетсе, бот сізге автоматты түрде Telegram-ға логтарын жібереді.
